# 청구 업무 규칙

> 테스트용 자료(FIXTURE) — 실제 프로젝트 정책이 아니다.

### `BIL-001` 결제 수단 토큰 보관

- 상태: 확정
- 근거: docs/decisions/payment-token.md

카드 번호 대신 결제 수단 토큰만 보관한다. 카드 유효기간이 만료되면 결제 수단 토큰도 삭제한다.

### `BIL-002` 청구서 발행 시점

- 상태: 확정
- 근거: docs/decisions/invoice.md

매월 1일 0시에 전월 사용분 청구서를 발행한다.

### `BIL-003` 청구서 재발행

- 상태: 관찰

청구서 금액이 바뀌면 기존 청구서를 취소하고 새 번호로 청구서를 재발행한다.

### `BIL-004` 환불 처리 기한

- 상태: 확정
- 근거: docs/decisions/refund.md

환불은 요청을 받은 뒤 영업일 3일 안에 처리한다.

### `BIL-005` 구독 갱신 결제 실패

- 상태: 확정
- 근거: docs/decisions/renewal.md

구독 갱신 결제가 실패하면 3일 간격으로 3번 다시 시도하고, 모두 실패하면 구독을 정지한다.

### `BIL-006` 구독 해지

1. 상태: 확정

구독을 해지하면 남은 기간은 일할 계산해 환불하고, 다음 갱신 결제를 만들지 않는다.
