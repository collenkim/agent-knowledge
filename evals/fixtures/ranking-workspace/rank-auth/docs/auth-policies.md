# 인증 정책

> 테스트용 자료(FIXTURE) — 실제 프로젝트 정책이 아니다.

### `AUTH-POL-001` 비밀번호 재설정 토큰 만료

- 상태: 확정
- 근거: docs/decisions/reset-token.md
- 범위: `PATCH /auth/password`

비밀번호 재설정 토큰은 발급 후 15분이 지나면 만료된다. 만료된 토큰으로 요청하면 410을 돌려준다.

### `AUTH-POL-002` 로그인 실패 잠금

- 상태: 확정
- 근거: docs/decisions/login-lock.md
- 구분: 필수

같은 계정으로 로그인에 5번 연속 실패하면 계정을 10분 동안 잠근다. 잠긴 동안에는 올바른 비밀번호도 거절한다.

### `AUTH-POL-003` 세션 유지 시간

- 상태: 관찰

현재 세션은 마지막 요청 뒤 30분 동안 유지된다.

### `AUTH-POL-004` 관리자 다중 인증

상태: 미확인

관리자 계정은 다중 인증을 써야 한다고 들었지만 확인되지 않았다.
